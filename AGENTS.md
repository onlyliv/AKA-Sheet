# Beta branch rules

Read VERSIONING.md and BETA-PLAN.md before edits. Work on beta/local-translation in this clone. Do not edit/publish the stable source at ../akai-sheet or deploy to the stable Site. Only user approval may raise the major version or merge the beta into stable. Record feature changes as minor releases and bug fixes as patch releases; prereleases use -beta.n. Keep the current release, UI asset cache keys, local package and release log aligned.

Book content must stay on the user's device. Do not add hosted OCR/translation APIs. Never auto-download large translation weights before the user selects download permission. NLLB remains experimental, noncommercial, removable and subject to future removal review. Preserve EPUB sandbox restrictions.
