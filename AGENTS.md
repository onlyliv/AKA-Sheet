# Beta branch rules

Read VERSIONING.md and BETA-PLAN.md before edits. Work on main in this clone. Publish this main clone only to its existing public Site when requested. Do not edit unrelated source clones. Only user approval may raise the major version or merge the beta into stable. Record feature changes as minor releases and bug fixes as patch releases; prereleases use -beta.n. Keep the current release, UI asset cache keys, local package and release log aligned.

Book content must stay on the user's device. Do not add hosted OCR/translation APIs. Never auto-download large translation weights before the user selects download permission. NLLB remains experimental, noncommercial, removable and subject to future removal review. Preserve EPUB sandbox restrictions.

2026-11-16 user authorization: apply i18n to both main and beta, publish their existing Sites and update GitHub. Transfer only localization changes to main; do not merge Drive beta features.
