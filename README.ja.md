# AKA Sheet

[한국어](README.md) · [English](README.en.md) · 日本語

PDF・DRMのないEPUB・画像の本に対応した、オフライン志向の学習リーダーです。色付きの答えを隠し、選択した範囲を端末内で認識・翻訳し、蛍光ペン、テキスト／描画メモ、辞書、単語帳で学習できます。

- [公開アプリを開く](https://akai-sheet-beta-local-7k29.g-flow.chatgpt.site/) · main **1.1.0**
- [Drive同期ベータを開く](https://aka-sheet-drive-beta-7k29.g-flow.chatgpt.site/) · beta **1.10.0-beta.1**

公開版とDriveベータは別のサイト・保存領域です。Google Drive同期はベータのみに含まれます。

## 表示言語

韓国語・英語・日本語に対応します。初回はシステム言語に従い、未対応の言語では英語を表示します。**設定 → メニューUI → アプリの表示言語**から変更できます。作業を中断しないよう、変更は次回起動から適用します。

UI言語はOCR・翻訳・辞書の言語とは独立しています。本の本文、メモ、単語の意味、過去の開発記録は原文を保持します。

## 試す

本を用意せずに内蔵の体験用シートで試せます。色を選んで**色を隠す**を押してください。本を開いたら**範囲選択**からOCR・蛍光ペン・メモ・翻訳・辞書・単語帳へ進めます。

本の原本は端末内に保持し、OCR・翻訳も端末内で処理します。準備したモデルや辞書はオフラインで再利用できます。初回準備には接続と保存容量が必要で、端末・ブラウザーにより対応状況は異なります。大型翻訳モデルと辞書は選択時のみダウンロードします。NLLBは実験用・非商用です。

## ローカル実行

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory public
```

`http://127.0.0.1:8765/`を開いてください。保存領域はサイト・ポート別です。移動やサイトデータ削除の前に大切な学習記録を書き出してください。

翻訳の追加・検証は[i18n資料](docs/I18N.md)、設計と制限は[開発事例](docs/PORTFOLIO.md)を参照してください。

描画モードでページ全体に書き込めます。ツールは移動でき、設定 → メニュー UIで従来の範囲指定の描画メモに切り替えられます。
