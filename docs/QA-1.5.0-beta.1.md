# 1.5.0-beta.1 · UI i18n 검증

- 지원: 한국어, 영어, 일본어. 시스템 언어 선택과 기기별 수동 설정, 미지원 언어 영어 대체, 다음 실행 적용.
- 50개 CJS 검사 통과. 번역 목록 1,076개, 두 번역 언어 누락·변수 일치와 HTML/JS 사용 키 검사.
- 한국어 초기 화면 → 영어 메뉴/설정 전환, 일본어 OCR 설정, 390px 영어 설정 화면 확인.
- 베타는 영어 설정 탭 전체에서 한국어 UI 잔여 문구 없음 확인. 언어 선택 항목의 한국어/日本語 자국어 표기와 사용자 내용·과거 기록은 의도적으로 원문 유지.
- 실행 Worker의 UI 언어 전달과 언어별 URL의 오프라인 캐시 재사용 검사. 모델 자동 다운로드 정책·학습 데이터 형식은 변경하지 않음.
- 공개 main은 기존 정적 앱에 i18n만 적용하며 Drive 베타 기능·인증 서버를 포함하지 않음.
- 브라우저 화면 증거는 저장소 외부 AKA-Sheet-QA/i18n-*.jpg. 실제 배포 결과는 게시 후 추가 기록.
- 모든 언어의 원어민 교정, 실물 모바일 기기 및 모든 오류 경로의 시각 검증은 미실시.
