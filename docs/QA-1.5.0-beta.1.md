- 지원: 한국어, 영어, 일본어. 시스템 언어 선택과 기기별 수동 설정, 미지원 언어 영어 대체, 다음 실행 적용.
- 50개 CJS 검사 통과. 번역 목록 1,076개, 두 번역 언어 누락·변수 일치와 HTML/JS 사용 키 검사.
