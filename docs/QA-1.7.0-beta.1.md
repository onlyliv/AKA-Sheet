# 1.7.0-beta.1 · 모바일 리더 UI 검증

2026-11-17. 사용자 승인에 따라 공통 모바일 UI와 페이지 전체 그리기 모드를 main/beta에 적용. Google Drive 연결·토큰 갱신·동기화는 베타 전용으로 유지한다.

- 모바일 탭: 학습 시트 → 영역 선택 → 메모/단어장 → 책 설정. 기존 DOM을 이동해 이벤트·입력·책 상태를 공유한다. 메뉴 표시 설정을 존중하고 내용 높이에 맞춘다.
- 형광펜·메모 탐색기 개수는 접기 버튼 왼쪽. 접근성 이름은 종류와 개수를 유지한다.
- 모바일 Sheet ON/OFF 배지 제거. ON은 로고 문자만 숨기고 선택 색상 조합에 따른 배경은 그대로 유지한다. 제목 색상으로 상태를 표시한다. PC는 기존 배지를 유지한다.
- 설정 제목 오른쪽 PC/모바일 버튼으로 실제 앱 레이아웃을 전환하고 기기에 선택을 저장한다. 인식·선택 진행 중 또는 저장 실패 시 전환하지 않는다. 기본은 기기 너비를 따른다.
- 책 설정의 두 선택 상자는 같은 너비, 배율 버튼은 가로 전체, 페이지 이동은 중앙.
- 페이지 전체 그리기 모드, 도구 이동, 기존 영역 그리기 메모 선택, 실제 획 위치 탐색을 공통 지원한다. main의 로컬 백업도 페이지 필기 저장을 감지한다.

## 검사

- 두 브랜치 자동 검사 총 94개 통과. 레이아웃 전환의 노드 동일성·복귀·탭·기기별 선택·실패 가드 추가 검사. 기존 저장/복원·필기·OCR·선택·번역·사전·단어장 검사 통과.
- 각 앱 JS 구문 검사, HTML 중복 ID 없음, 기동 진행률과 캐시/스크립트 버전 일치.
- Chrome 402×874 및 360×780 화면에서 한국어·영어·일본어 메뉴 확인. 학습 시트 메뉴 높이 173px/874px, 책 설정 216px/780px. 가로 넘침 없음; 페이지 인디케이터 중심 180px/360px; 배율 행 342px/메뉴 내부 342px.
- 정식 버전에서 페이지 필기 입력·저장·탐색·새로고침 후 복원 확인. 메모 편집 중 PC 전환 후 초안 내용 유지 확인. 메뉴 숨김/복귀 확인.
- main 실행 스크립트에 Drive/sync 모듈이 없음을 확인. 베타 동기화 서버 코드는 변경하지 않는다.

## 검증 범위

실제 iPhone/Galaxy 하드웨어·펜·모바일 Safari 검증은 별도 필요하다. 브라우저 검증은 예제 페이지로 진행했으며 실제 책 파일의 업로드와 기기간 Google 재인증/동기화는 이번 UI 변경에서 다시 실행하지 않았다.
