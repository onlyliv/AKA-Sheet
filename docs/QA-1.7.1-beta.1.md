# 1.7.1-beta.1 · iPhone 웹앱 안전 영역

2026-11-17. 사용자 스크린샷에서 상태 표시줄 아래 흐림이 앱 헤더까지 겹치는 현상을 확인. iOS 실기기에서는 아직 재검증하지 않았다.

- viewport-fit=cover 유지, 상태 표시줄 스타일 default 명시. HTML/manifest 테마와 안전 영역 배경을 불투명한 메뉴 배경색으로 통일.
- body에 상하좌우 env(safe-area-inset-*)를 한 번 적용. main은 남은 body 내용 높이 100%를 사용하며 책·메뉴 상태에 따라 중복 여백을 추가하지 않는다.
- 메뉴 열기 버튼은 안전 영역 안쪽 8px. 책 열기 팝업은 이동된 버튼 위치를 기준으로 기존 배치를 유지.
- CSS 공유 수정이며 Google 동기화 기능은 변경하지 않음. main에 동기화 코드를 추가하지 않음.

검사: 기존 자동 검사 94개 통과. Chrome 402×874 화면에 상단 62px/하단 34px를 주입한 임시 검증 화면에서 main top=62, bottom=840, height=778 확인. 헤더 top=62, 메뉴 숨김 후에도 main top=62, 열기 버튼 top=70. 가로 넘침 없음. 임시 검증 화면은 배포에서 제외.

한계: Chrome의 여백 검증은 iOS의 실제 시스템 흐림을 재현하지 않는다. 설치된 iPhone 웹앱을 닫았다 다시 열어 사용자 실기기 확인이 필요하다. 사이트 데이터 삭제는 필요하지 않다.
