# Google Drive 자동 갱신 검증

- 서버 인증 정보 암호화, 플랫폼 사용자·기기 쿠키 격리, POST 출처 검사, 접근 토큰 만료 후 갱신, 갱신 토큰 변경 보존, 동시 갱신 통합, Drive401의1회 갱신, 연결 해제 및 Google 철회를 검증.
- 브라우저 어댑터는 코드만 서버로 전달하고 인증 토큰을 받거나 보관하지 않음. 기존 로컬 어댑터 및 학습 데이터 회귀 검사 유지.
- 기존 브라우저 액세스 토큰은 웹 서버 연결 복원 단계에서 제거. 기존 학습 데이터·캐시·Drive 기록은 유지.
- 서버에는 학습 기록을 영구 보관하지 않지만 API 전송은 서버를 거침. 해당 변경은 개인정보 안내에도 반영.
- 실제 Google 동의 및 만료 후 서버 갱신의 외부 검증은 배포 후 진행. 테스트 상태7일 제한 및 기기 쿠키180일 상한이 있으며 무기한 연결을 보장하지 않음.

- 서버 전환으로 정적 원본을 public/, 생성 결과를 dist/client·dist/server로 분리. 중복 자산을 제외해256MiB 업로드 제한 준수. 테스트와 로컬 실행 경로도 public 기준으로 변경.

- 실제 코드 인증·계정 확인·암호화 보관 성공 후 Drive 조회에서 Workers가 지원하지 않는 redirect:error로 즉시 TypeError가 발생함을 공식 런타임 문서로 확인. manual로 변경하고 같은 옵션 재발 방지 검사 추가.
