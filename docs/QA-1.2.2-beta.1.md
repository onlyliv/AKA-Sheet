# 저장 설정 및 병행 사용 검토

- 로컬 저장소 설정을 Drive와 같은 카드로 구분. 자동 저장 제어 유지, 수동 내보내기와 시각 배치 정리. 실제로 브라우저 내부 데이터를 사용하며 폴더 파일은 별도 복구본이다.
- Drive 동기화는 학습 기록을 합친 뒤 UserData.changed를 호출하므로 폴더 자동 저장이 켜져 있으면 수신 기록도 파일에 저장된다. 폴더 파일을 자동으로 읽어 역방향 동기화하지 않는다.
- 스냅샷과 데이터 병합은 공통 Web Lock, 로컬 파일 쓰기는 별도 파일 Web Lock으로 직렬화한다. Drive가 반영되는 동안의 내보내기는 반영 전 또는 후의 일관된 스냅샷을 받는다. 파일 쓰기가 끝나기 전 새 변경이 생기면 다음 저장을 예약한다.
- 다른 앱/기기가 자동 파일을 바꾸면 해시 불일치로 덮어쓰기를 중단한다. OS 파일 잠금이 아니므로 여러 브라우저·기기에서 같은 파일을 동시에 편집하는 사용은 지원하지 않는다. 기기별 폴더를 권장한다.
- 오래된 백업 불러오기는 현재 데이터와 병합한다. 삭제했던 항목이 다시 추가되거나 같은 ID의 다른 내용이 복사본으로 남을 수 있으며, 복원한 기록도 Drive로 전송된다.
- 브라우저 사이트 데이터 삭제 후에는 폴더 권한과 연결 설정을 다시 지정하고 파일을 불러와야 한다. 마지막 파일 저장 이후 변경은 로컬 파일만으로 복구되지 않는다.
- 앱 설정은 로컬 백업에는 포함되지만 Drive 전송에서 제외된다. 책 원본·모델·사전팩·인증은 백업 대상이 아니다.
- 동기화 상태를 책 화면 상단바로 이동하고 설정 바로가기 유지. EPUB 입력층 위치도 새 상단바 기준으로 조정.

## 과거 데이터 덮어쓰기 보호
- 로컬 복원은 현재 설정과 읽기 위치를 우선하며 현재 없는 값만 채운다. 이미지 책의 현재 위치도 유지한다. 항목 내용이 다르면 별도로 보존한다. 과거 백업에서 삭제 항목이 다시 추가될 수 있다는 점은 별개다.
- Drive는 부모 버전 관계를 사용하므로 이미 확인한 과거 버전은 최신 버전이나 삭제를 덮어쓰지 않는다. 서로 상대 변경을 보지 못한 편집은 내용 복사본으로 보존하며, 동시에 변경한 읽기 위치는 변경 기록 시각으로 선택한다. 기기 시계와 장기간 오프라인 수정만으로 절대적인 최신 순서를 보장하지는 않는다.
