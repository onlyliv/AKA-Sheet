# AKA Sheet 1.0.0 · 메뉴 사용자화 검증

검사일: 2026-11-16. 사용자의 메이저 버전 승인과 앱 이름의 베타 제거 요청을 반영했다. 기존 사이트 주소·저장소 키·DB 스키마·Paddle 및 번역 모델 캐시 구분은 유지한다. 별도 0.9.0 안정판 사이트/브랜치 병합은 하지 않았다.

## 구현

- 설정의 메뉴 UI 표에 순서 이동(위/아래)과 기본 순서 복원. 순서, 표시, 시작 시 펼침을 독립적으로 저장. 저장 전에는 초안이며 닫으면 기존 값 유지.
- PC 좌측/모바일 상단 메뉴 전체 숨김. 숨김 상태를 저장하며 첫 실행은 표시. 복귀 버튼은 PC 좌측 상단, 모바일 우측 상단, 44×44px.
- 숨김 시 메뉴/크기 조절 막대를 읽기·키보드 탐색에서 제외. 책 공간을 전체 화면으로 확장. 복귀 시 기존 구성과 크기 유지. 버튼은 페이지 넘김/영역 선택 이벤트와 분리.
- PC 설정 버튼은 하단 개발 로그 옆, 모바일은 기존 상단 위치. 화면 크기를 바꾸어도 설정 버튼은 하나이며 실제 DOM 위치를 이동.
- OCR/번역 실행, 책 렌더링 및 메모 초안 편집 중에는 메뉴 전환을 막아 작업 손실 방지. 진행 중이 아닌 영역 선택은 레이아웃 변경 시 기존 취소 경로 사용.
- 설정 키는 akai.settings.v1 유지. menuOrder/menuCollapsed만 추가하고 이전 설정은 기본 순서/표시 상태로 보완. 기존 사용자 데이터 JSON 백업에 포함, 복원 검사.
- 문서 제목·기동 화면·사이트 표시명을 AKA Sheet로 통일. NLLB 실험용·비상업 안내 및 과거 개발 로그는 유지.
