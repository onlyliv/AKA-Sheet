# 1.2.1-beta.1 검증

- 인증 저장소: AES-GCM 암호화, 재실행 복원, 만료·잘못된 클라이언트·연결 해제 시 제거 검증. 인증은 백업과 동기화에서 제외.
- 두 독립 기기 저장소와 공용 Drive 모형: 자동 수신·새로고침 없는 적용, 오프라인 수정, 충돌·삭제, 재실행과 자동 동기화 끄기 상태 유지 검증.
- Google 브라우저 인증의 약 1시간 유효기간 이후에는 재연결이 필요함. 장기 로그인은 refresh token을 안전하게 관리하는 서버 방식이 필요하며 이번 변경에 포함하지 않음.
- 45개 테스트와 전체 배포 스크립트 문법 검사 통과.
- 웹 베타 실제 Google 로그인 직후 자동 수신으로 형광펜 요약 6→7개 반영 확인. 새로고침 후 계정 선택 창 없이 동일 계정 연결 복원 및 자동 동기화 재시작 확인.
- 물리 기기 두 대에서의 추가 교차 검증은 사용자 테스트로 남음.
