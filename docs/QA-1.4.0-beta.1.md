# 5분 동기화 및 V2 검증

- 5분 고정 주기와 페이지/편집/복귀의 별도 요청 제거, 다음 주기 재시도 검사.
- 서버 모형에서 유휴 head50회 동안 Google 호출0회, 기기8회 업로드 후 기기 파일 최대2개, ACK 재시도 추가 업로드0회 검증.
- 실제 IndexedDB 두 기기 모형으로 즉시 전송 대기 보존, 전송 중 새 변경 보존, ACK 유실 재시도, 대표 탭 하나, 빈 새 기기 복원, 마지막 항목 삭제 후 재실행 전송 확인.
- 기존 V1 이전 후 검증 전 원본 보존, 통합 상태와 복구본, 오래된 기기 수정의 충돌 보존, 쓰기 실패의 기존 파일 보존 검사.
- 통합은 값 본문을 제거하되 인과 관계와 삭제 기록을 보존한다. 무한 이력 지원은 아니며100,000개 작업 및25MB 파일 한도는 남는다.
- 서버 유지보수는 앱이 실행 중일 때 다음 주기에 동작한다. 앱이 닫힌 동안 Google에 미전송 변경이 자동 도착하는 기능은 아니다. 사이트 데이터 삭제 전 미전송 기록은 별도 폴더 백업이 없으면 유실될 수 있다.
- 실제 웹 배포에서 기존 계정 이전·복원·유휴 호출과 UI 확인은 배포 후 기록한다.
