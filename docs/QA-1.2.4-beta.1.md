# 동기화 기동 속도 및 저장소 초기화 보호

- 이전 웹 베타에서 재실행→완료 약21.3초 측정. 원인은 매 실행 전체 파일 순차 수신.
- 신규 버전은 계정/클라이언트별 검증된 파일 캐시를 기기에 보관하고, 목록 메타데이터가 같은 파일은 다운로드 생략. 캐시 파일 checksum 재검증. 기존 Drive 데이터는 삭제하거나 통합하지 않음.
- 최초/캐시 없는 실행은 최대4개 동시 다운로드. 합계50MB 기존 제한 유지. 오류가 나도 진행 중 요청은 모두 끝난 뒤 중단하므로 다음 동기화와 작업이 겹치지 않음.
- 캐시 삭제/손상, 빈 신규 기기, 데이터 DB만 비고 journal/읽기 위치가 남은 기기, 다운로드 실패, 재실행 추가 다운로드0건을 두 기기 모형으로 검사. 빈 기기에서 삭제 파일이나 빈 덮어쓰기 전송이 없는지 확인.
- 실행 시 비어 있는 그룹은 복원 우선. 동기화 전에 마지막 항목을 오프라인 삭제하고 종료한 경우 의도한 삭제와 데이터 유실을 구별할 수 없어 복원될 수 있음. 비어 있지 않은 일부 항목 손실까지 탐지하는 기능은 아님.
- 인증은 기존 약1시간 유효 인증 복원 방식 그대로이며 장기 로그인은 별도 작업.
