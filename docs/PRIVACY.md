# Google Drive 베타 데이터 처리 안내

적용 버전: 1.3.0-beta.1 · 갱신: 2026-11-16

AKA Sheet는 책을 사용자의 기기에서 여는 학습 앱입니다. Google Drive 동기화는 선택 기능이며 연결하지 않아도 기존 로컬 학습 기능을 사용할 수 있습니다.

## 기기에 저장하는 정보

형광펜, 메모, 단어장, 읽기 위치, 설정은 브라우저의 IndexedDB/localStorage 등에 저장합니다. 사용자가 연결한 로컬 폴더에는 사용자 데이터 JSON을 저장할 수 있습니다. 모델·사전팩은 별도 로컬 캐시에 저장합니다. 브라우저 저장 데이터를 지우면 내부 기록과 복구 데이터가 사라질 수 있습니다.

## Google 연결 시

Google 로그인은 Google의 로그인 화면과 Identity Services를 사용합니다. 앱은 `openid`로 연결 계정을 구분하는 식별자와 `drive.appdata`로 앱 전용 Drive 저장 공간 접근 권한을 요청합니다. 전체 Drive 파일, 이메일, 연락처 접근 권한은 요청하지 않습니다. 웹 베타의 접근·갱신 토큰은 서버 D1에 AES-GCM으로 암호화해 보관하며, Sites 비밀 설정의 키로만 해독합니다. 브라우저에는 토큰을 전달하지 않고 기기별 HttpOnly·Secure·SameSite 보안 쿠키를 사용합니다. 서버는 호스팅이 제공하는 로그인 사용자와 쿠키를 함께 확인합니다. 인증은 학습 백업·Drive 기록·GitHub에서 제외합니다. 로컬 정적 실행에는 기존 단기 토큰 방식이 남아 있습니다.

Google 로그인과 OAuth 권한 승인 후 자동 동기화하면 형광펜 및 저장된 인식 텍스트, 텍스트·그리기 메모, 단어장·단어·뜻·사전 출처, 책/페이지 식별자, 이미지 책 목록과 읽기 위치를 본인 Google Drive의 앱 전용 공간에 저장합니다. 기록에는 사용자가 선택한 책의 일부 인식 텍스트나 메모 내용이 포함될 수 있습니다. 원본 책 전체, 모델·사전팩, 폴더 권한, 기기별 UI 설정, 임시 결과는 전송하지 않습니다.

웹 베타의 학습 데이터 요청은 권한을 관리하는 앱 서버를 거쳐 Google Drive로 전달됩니다. 서버 DB에는 학습 기록이나 책 원본을 저장하지 않으며, Google 식별자·기기별 인증 정보·연결 만료 시각만 저장합니다. 통신은 HTTPS를 사용하지만 앱 자체의 종단 간 암호화는 아직 없습니다. Google 서비스 이용에는 Google의 정책이 별도로 적용됩니다. 앱·모델을 다운로드하는 호스팅 제공자와 Google 로그인 서비스에는 해당 요청에 필요한 네트워크 정보가 전달될 수 있습니다.

## 보관·해제·삭제

웹 베타의 연결 해제는 해당 기기의 쿠키와 서버 인증 레코드를 제거하고 동기화를 중지합니다. 다른 기기의 연결은 유지됩니다. 연결 쿠키의 상한은180일이며 Google의 권한 만료·철회 및 브라우저 쿠키 삭제 시 재연결이 필요합니다. 로컬 기록과 Drive 기록은 자동 삭제하지 않습니다. Google 계정의 연결 앱 관리에서 접근 권한을 철회할 수 있으며, Drive의 연결 앱/앱 데이터 관리에서 저장 데이터를 제거할 수 있습니다. Google 관리 화면에서 데이터를 삭제하면 복구하지 못할 수 있습니다.

베타는 변경·삭제 이력을 누적 보관하며 앱에서 항목을 삭제해도 Drive의 과거 변경 파일은 자동으로 지우지 않습니다. 동일 계정으로 여러 기기를 연결하면 각 기기가 해당 계정의 앱 데이터를 가져올 수 있습니다. 다른 계정으로 바꾼 뒤 전송에 동의하면 현재 기기의 학습 기록을 새 계정에도 저장합니다.

공개 배포 전 Google 연결·동기화 검증이 더 필요합니다. 문의는 [GitHub Issues](https://github.com/onlyliv/AKA-Sheet/issues)에서 할 수 있으며, 비밀 키·토큰·개인 학습 데이터를 공개 이슈에 올리지 마세요.
