# 1.8.0-beta.1 검증

범위: beta/google-drive-sync 및 전용 Drive 베타 Site. main 변경 없음.

## 완료

- 자동 검사 53개 통과. 저장·예문 길이·중복·기존 필드 보존·검색/내보내기·백업 무결성·복원 충돌·동기화 수렴 및 구형 편집기의 예문 유실 방지 포함.
- 생성 문서의 HTML 이스케이프, 일본어만 ruby, 페이지 구성/정렬/긴 텍스트 한도, i18n ko/en/ja 및 오프라인 리소스 검사.
- Chrome 실제 UI에서 전용 QA 단어장 생성, 일본어 후리가나/예문과 영어 단어 저장, 책 열기, 학습표형/한 단어형, 페이지 이동과 기존 체험 책 복귀 확인. 기존 사용자 단어장은 편집하지 않음.
- 402×874 모바일 화면에서 예문 아래 배치, PC에서 뜻 옆 배치. 모바일 책 설정 탭에 보기 옵션 배치 및 PC 복귀 확인.
- 빨강 색상 숨김 시 뜻/예문 해석 숨김, 원문 예문과 단어/후리가나 유지 확인. 브라우저 오류 로그 없음.

## 제한

- 실제 iPhone 및 두 기기 간 Google 동기화는 이번 실행에서 재검증하지 않음. 동기화/백업 데이터 경로는 자동 검사로 확인.
- 단어 원문이 바뀐 필드의 이전 선택 주석과 페이지 구성이 바뀐 페이지 필기는 다른 위치에 잘못 표시하지 않도록 숨기며 원본은 보존.
- 원본 EPUB/PDF/이미지는 서버에 전송하지 않음. 단어장 문서는 기기 안에서 생성하며 기존 sandbox를 사용.
