# Google Drive 동기화 베타 · 1.2.1-beta.1

브랜치: `beta/google-drive-sync`. `main`과 현재 공개 앱은 1.0.0을 유지합니다. 웹 베타: https://aka-sheet-drive-beta-7k29.g-flow.chatgpt.site/ . 공개 클라이언트 ID를 앱에 포함하며 사용자는 Google 연결만 하면 됩니다. 개발자가 새 주소를 OAuth 원본에 등록했습니다. 이 베타는 소유자 접근으로 배포하므로 다른 기기에서도 같은 ChatGPT 계정으로 사이트에 접근한 뒤 같은 Google 계정을 연결합니다.

## 1. 로컬 실행

```sh
git switch beta/google-drive-sync
python3 -m http.server 8789 --bind 127.0.0.1 --directory dist
```

`http://127.0.0.1:8789/`를 Chrome에서 엽니다. 기존 서비스와 다른 주소이므로 기존 사이트의 데이터가 자동으로 표시되지는 않습니다. 시험할 데이터가 필요하면 기존 앱에서 수동 백업한 뒤 베타에 불러오세요. 원본 백업을 보관하세요.

## 2. Google Cloud 설정

개발자가 한 번 등록합니다. 앱 사용자마다 개발자 프로젝트를 만들 필요는 없습니다.

1. [Google Cloud Console](https://console.cloud.google.com/)에서 이 앱 전용 프로젝트를 만듭니다.
2. Google Drive API를 사용 설정합니다. 이 베타에는 자체 서버·서비스 계정·유료 인프라가 필요하지 않습니다. 과금이나 유료 상품 활성화는 요구하지 않습니다.
3. Google Auth Platform에서 앱 이름·지원 이메일·대상 사용자를 설정합니다. 앱 홈페이지와 개인정보 안내 URL이 필요하면 공개된 프로젝트 소개와 [데이터 처리 안내](PRIVACY.md)를 사용하되, Google의 도메인 요구 사항을 확인합니다. 외부 사용자 대상의 테스트 상태로 시작하고, 실제 시험할 Google 계정을 테스트 사용자에 등록합니다.
4. 요청 범위에 `openid`와 `https://www.googleapis.com/auth/drive.appdata`를 추가합니다. 전체 Drive 접근 권한은 필요하지 않습니다.
5. OAuth 클라이언트를 **웹 애플리케이션**으로 만들고, 승인된 JavaScript 원본에 정확히 `http://127.0.0.1:8789`를 등록합니다. `localhost`는 다른 원본이므로 필요하면 별도로 등록합니다. 토큰 방식 팝업을 사용하므로 이 구현의 로그인 완료용 리디렉션 URL은 없습니다.
6. 생성된 **클라이언트 ID**(`….apps.googleusercontent.com`)만 개발용 `dist/drive-config.js`에 넣습니다. 비밀 키는 입력하거나 GitHub에 올리지 마세요.

앱을 배포할 때는 `dist/drive-config.js`에 공개 클라이언트 ID를 넣고, 별도 베타 HTTPS 주소를 승인된 JavaScript 원본에 추가합니다. 현재 베타에는 공개 클라이언트 ID가 포함되어 있습니다. Google 로그인은 사용자가 직접 시작합니다. OAuth 클라이언트 ID는 같은 Google Cloud 프로젝트를 사용하는 기기들이 공통으로 사용해야 동일 앱 데이터 공간을 조회할 수 있습니다.

현재 공유 호스팅 주소에 대한 도메인 소유 확인이나 Google의 앱 공개·브랜드 검증이 필요한 경우 별도 조치가 필요합니다. 로컬 테스트부터 완료하고, Google의 실제 검증 요구를 확인한 뒤 공개 배포하세요. 테스트 사용자 외 모든 사람에게 곧바로 연결된다고 보장하지 않습니다. 기존 운영 Sites 프로젝트에 이 브랜치를 배포하지 마세요.

공식 문서: [브라우저 토큰 방식](https://developers.google.com/identity/oauth2/web/guides/use-token-model), [Drive 앱 데이터 공간](https://developers.google.com/workspace/drive/api/guides/appdata), [요청량·요금 정책](https://developers.google.com/workspace/drive/api/guides/limits).

## 3. 두 기기에서 사용하기

1. 각 기기에서 같은 웹 베타를 엽니다. 소유자 전용이므로 같은 ChatGPT 계정으로 사이트에 접근합니다.
2. 설정 → 저장 데이터 관리 → **Google 로그인**으로 같은 Google 계정을 연결합니다. OAuth 화면에서 앱 데이터 접근을 승인하면 자동 동기화가 시작됩니다. 별도 전송 체크나 수동 적용은 없습니다.
3. 자동 동기화는 기본 ON이며, 원하지 않으면 **자동 동기화** 옵션 하나를 끕니다. OFF 선택은 해당 기기에 유지됩니다.
4. 같은 책 원본은 기기별로 직접 엽니다. 내용이 같은 파일은 이름·수정 시각이 달라도 같은 책의 주석과 위치를 연결합니다.

형광펜·메모·단어장 변경은 3초 후(연속 변경 최대 15초), 누적 6페이지 이동·번호 지정 이동·변경이 남은 상태의 5분 무활동에도 전송합니다. 다른 기기의 변경은 사용 중 30초 간격 및 화면 복귀/인터넷 재연결 시 확인하며, 편집·선택 중이면 완료 후 자동 반영합니다. 적용 시 앱을 새로고침하지 않습니다.

웹 베타는 Google 코드 인증을 사용합니다. 서버에서 접근 권한을 자동 갱신하며 브라우저에는 토큰을 전달하지 않습니다. 기존 단기 연결에서 전환할 때 Google 계정을 한 번 다시 연결해야 합니다. 기기별 보안 쿠키 상한은180일이고, Google에서 권한을 취소하거나 쿠키를 지우면 다시 연결해야 합니다. Google OAuth 동의 화면이 테스트 상태이면 갱신 토큰도7일 후 만료될 수 있으므로 장기 운영에는 프로덕션 게시가 필요합니다.

서버 설정 키: `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `DRIVE_TOKEN_KEY`(32바이트 Base64), `APP_ORIGIN`. 비밀값은 Sites 런타임 비밀 설정으로만 관리합니다. `.openai/hosting.json`의 D1 `DB`에는 기기 인증 레코드만 저장합니다. 배포는 `node scripts/build-server.mjs`로 Worker와 기존 정적 자산을 패키징합니다. 정적 로컬 실행은 이전 단기 인증 방식입니다.


## 데이터 범위와 보존

| 포함 | 제외 |
|---|---|
| 형광펜과 저장된 인식 텍스트, 텍스트·그리기 메모, 단어장과 단어·사전 출처, 이미지 책 목록/페이지 식별, 읽기 위치 | 책 원본, OCR·번역 모델, 사전팩, 폴더 핸들/권한, 인증 토큰, 기기별 UI·엔진 설정, 임시 OCR/번역 결과 |

Drive 파일은 앱 전용 숨김 공간에 저장되므로 일반 Drive 파일 목록에는 나타나지 않습니다. 기존 로컬 폴더 저장·JSON 백업/복원도 유지합니다. 다른 계정으로 연결하고 동의하면 현재 기기의 학습 기록이 그 계정으로도 전송됩니다. 계정을 바꾸는 것은 기기 데이터를 비우는 동작이 아닙니다.

같은 항목을 두 기기에서 동시에 수정하면 둘을 복사본으로 보존합니다. 수정과 삭제가 충돌하면 아직 관찰하지 못한 수정본을 보존합니다. 같은 단어장 이름·아이콘과 같은 단어·뜻은 중복 표시를 줄입니다. 단어장 삭제와 소속 단어 편집이 충돌하면 단어가 유실되지 않도록 단어장도 보존합니다. 읽기 위치·이미지 책 위치는 기록 시각과 ID로 일관되게 하나를 선택하므로 기기 시계가 다르면 실제 최신 위치와 다를 수 있습니다.

종료·복구 중단에 대비해 적용 전 기기 데이터와 동기화 기준을 IndexedDB에 보관합니다. 미완료 복구 기록이 있으면 새 동기화를 막고 복구 버튼을 표시합니다. 여러 DB에 걸친 적용은 하나의 원자적 트랜잭션이 아니므로 복구가 필요할 수 있습니다. 이 복구 기록도 브라우저 내부 데이터이며 별도의 백업을 대체하지 않습니다.

## 베타 한계

- 불변 변경 파일을 누적하고 클라우드 기존 파일을 삭제하지 않습니다. 장기 로그 압축/정리는 아직 없습니다.
- 파일당 25MB, 전체 50MB·파일 1,000개·변경 100,000개를 넘으면 중단합니다. 자동 과금 확대·즉시 무한 재시도는 하지 않습니다.
- 과거 이름·크기·수정시각 기반 읽기 위치는 개인정보와 기기별 불일치를 줄이기 위해 직접 전송하지 않습니다. 해당 파일을 이 베타에서 열면 내용 해시 기반 위치로 저장됩니다.
- 통신은 HTTPS이며, 업로드 데이터에 앱 자체의 종단 간 암호화는 아직 적용하지 않았습니다. 저장소는 사용자의 Google 계정입니다.
- 연결 해제는 메모리와 기기 인증 저장소를 해제하며 Google 권한·Drive 데이터·기기 데이터를 삭제하지 않습니다. 권한 철회는 Google 계정의 연결 앱 관리에서 할 수 있습니다.
- 실제 Google 로그인·Drive API, iOS/Android·Windows 기기 및 Google 공개 앱 검증은 설정 완료 후 시험해야 합니다. 자동 검사 통과만으로 실서비스 동기화 검증 완료라고 표현하지 않습니다.
