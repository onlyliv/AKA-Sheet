# 독서 화면 선명도 / 한국어 띄어쓰기 · 1.10.0-beta.2

- 변경 범위: beta/google-drive-sync만. main 및 Google 인증·동기화 프로토콜 변경 없음.
- 자동 회귀 검사: 58개 CJS 스위트 통과. 기본 OFF/독립 설정, 한국어만 보정, 비공백 문자 보존, 오인식 글자 변경 차단, 줄바꿈 연결·빈 문단 보존, 미동의 네트워크0, 다운로드 해시/MIME, 캐시 재사용·모델 삭제·손상 모델 활성 차단 포함.
- Chrome 브라우저 실측: Kiwi 0.24.1 WASM + CoNg 0.24.0 로드·첫 보정 약1339ms, 같은 샘플 재사용 약20ms. 데스크톱 단일 측정이며 다운로드 시간과 모바일 수치가 아님.
- 사용자 제공 OCR 샘플에서 `코드는프로젝트디렉터리에`→`코드는 프로젝트 디렉터리에`, `파일을읽고`→`파일을 읽고` 확인. 글자 오인식은 그대로 유지. 한국어 줄 중간의 단어 단절을 연결한 뒤 보정.
- 실제 브라우저에서 모델 선택 다운로드 완료, 새 Worker에서 캐시 재사용 확인. 두 번째 실행에 모델 파일을 재다운로드하지 않음.
- PC 메뉴 토글을 켜면 설정 체크도 ON, 모바일 책 설정에서 동일 토글·선택 스타일 확인. 402×874 Chrome 레이아웃 확인.
- 브라우저 생성 시험 EPUB의 이미지에는 필터 적용, 일반 텍스트 스타일 유지. 화면 보정 전/후 캔버스 및 EPUB OCR 캡처의 SHA-256 값 일치.
- 라이선스: Kiwi 코드·모델 Apache-2.0 및 구성 요소 NOTICE/원문 동봉. 선택 모델은 오프라인 셸의 사전 다운로드 대상에서 제외.
- 제한: iPhone/Android 실기기 성능, 저메모리 환경의 모델 초기화, 모든 교재의 보정 품질은 미검증. 브라우저 저장소 퇴거 시 OCR 원문을 제공하고 사용자 선택으로만 다시 다운로드. 긴 줄(2000자 초과)은 지연을 막기 위해 띄어쓰기 분석을 건너뜀.

- 호스팅 압축/확장256MiB 제한으로 모델 gzip 청크는 GitHub의 45c88d9 고정 커밋에서만 다운로드. runtime/manifest는 사이트 자체 제공. 모델 요청은 credentials omit / no-referrer이며 무결성 검증 후 동일 로컬 키로 저장. 배포 출력에서는 모델 청크만 제외.
