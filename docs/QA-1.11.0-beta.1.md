# 텍스트 추출 / 작은 선명도 버튼 · 1.11.0-beta.1

## 범위와 결과
- beta/google-drive-sync만 수정. main과 정식 Site는 변경하지 않음.
- 기존 텍스트 메뉴의 표시/접힘/순서 설정은 보존하고 이름만 변경. 중복 영역 선택 버튼 DOM 및 참조 제거.
- 실제 PC 버튼22×22px, 배율 줄22.5px. 다른 배율 버튼21.5~22.5px로, 새 아이콘이 행 높이를 늘리지 않음. 모바일402×874에서 버튼28×28px, 기존 배율 행36px 유지.
- 한국어·영어·일본어 UI/접근성 명칭 제공.

## 브라우저 실측 (데스크톱 Chrome, 단순 합성 시험 파일)
| 대상 | 결과 | 시간 |
|---|---|---|
| 텍스트 PDF100페이지 | 100페이지 원문 추출, 위치1 유지 | 약95.6ms |
| EPUB100개 본문 | 100개 원문 추출, 위치1 유지 | 약59.6ms |
| 스캔 PDF2페이지 | Paddle 영어OCR2페이지, Worker1개 | 약4.75초 |
| PNG ZIP3페이지(빈 이미지1장) | OCR3페이지, 텍스트 없음1, Worker1개 | 약7.48초 |

- 단순 파일의 단일 측정이며 실제 교재/모바일 성능 보장이 아님. 전체 스캔/자동 언어 추정은 더 오래 걸릴 수 있음.
- 현재 두 페이지 추출: 페이지1·2만 포함, 3은 제외. 전체100페이지 중 첫 페이지 후 취소하면1페이지 결과만 보존.
- EPUB의 script 실행 없음, hidden 텍스트/후리가나 중복 미포함, 원문 한·영·일 문자 보존.
- 학습 시트 ON: 추출 대화상자 열기 차단 및 해제 안내 표시.
- 기존 원문 선택/OCR/번역/단어장 회귀 포함60개 CJS 스위트 검사. 순차 처리, 취소 경합, 출력 상한, PDF 간격, OCR 엔진 재사용/해제 검사를 추가.

## 성능·지원 한계
- 한 페이지씩 렌더/OCR하고 임시 캔버스/떠난 PDF 페이지 데이터를 해제. 기존 이미지 책 표시 캐시는 건드리지 않음.
- 결과200만 자를 넘으면 명시적으로 중단하고 완료 페이지 결과를 보존. 미리보기5만 자, 복사/TXT는 확보한 전체 결과.
- PDF 텍스트 순서는 PDF 내부 문자 정보에 의존하며 복잡한 다단 편집은 검토 필요. EPUB은 원문 텍스트 또는 이미지 리소스를 사용하며, 텍스트 정보 없이 SVG 경로로만 그린 문자와 복잡한 CSS 배치는 완전한 복원이 보장되지 않음. 텍스트가 없는 결과 수를 표시.
- 섞인 페이지는 내장 텍스트 우선이므로, 해당 페이지 이미지 안의 추가 문자는 별도 영역 OCR이 필요할 수 있음.
- OCR 언어 자동은 여러 인식 모델을 반복 실행할 수 있음. 긴 전체OCR는 인식 언어 지정 권장. 앱을 닫으면 실행 중 작업이 이어지지 않음.
- iPhone/Android 실기기, 수천 페이지/저메모리 기기, 장시간 백그라운드 작업의 성능은 미검증.
