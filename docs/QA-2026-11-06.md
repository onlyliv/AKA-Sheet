# AKA Sheet 저장·오프라인 QA

검사일: 2026-11-06 / 대상: 0.38.1-beta.1 → 수정본 0.38.2-beta.1

## 범위와 판정

현재 Mac의 Chrome과 내장 Chromium 브라우저, 테스트 전용 localhost origin 및 폴더만 사용했다. 배포 사이트의 사용자 DB나 원본 책은 변경하지 않았다. 자동 검사는 격리된 IndexedDB/파일 모사 환경이다. 실기기 전체 QA 완료를 뜻하지 않는다.

오프라인 실측은 로컬 HTTP 서버를 종료하고 탭을 닫거나 다시 열어 앱의 서버 자원에 접근할 수 없게 했다. 번역 Worker는 download:false로 실행해 외부 모델 다운로드도 금지한다. 컴퓨터의 Wi-Fi/사용 중인 다른 앱의 네트워크는 끄지 않았다. 브라우저 프로세스 전체 종료·기기 재부팅은 포함하지 않았다.

## 발견하여 수정한 문제

1. Tesseract 코어 4개와 Transformers/ONNX 실행 파일 3개가 설치 캐시 목록에서 누락돼 있었다. 모델만 다운로드한 뒤 첫 OCR을 오프라인으로 실행하거나, 앱 업데이트로 이전 앱 캐시가 지워진 뒤 번역을 실행하면 실행 파일이 없어 실패할 수 있다. 7개 실행 파일(약 35MB)을 현재 버전의 설치 캐시에 포함했다. 모델 가중치와 사전팩의 선택 다운로드 정책은 유지한다. 기존 Paddle 준비 캐시·번역 모델 캐시는 삭제하지 않는다.
2. 저장소가 허용하는 선택 속성의 값이 undefined인 레코드는 JSON 파일에서 해당 키가 생략되지만 체크섬은 생략 전 내용을 사용해, 앱이 직접 만든 백업도 손상 파일로 거부했다. 직렬화된 데이터에 대해 검증·체크섬을 생성하도록 수정했다. 백업 스키마 1과 기존 정상 백업의 읽기 방식은 유지한다.

## 남은 실제 환경 검사

- Windows Chrome, Android Chrome, iOS의 파일 선택·수동 백업·복원 및 장시간 사용.
- 브라우저 완전 종료/기기 재부팅 뒤 폴더 권한 재연결, 디스크 부족·외부 저장 장치 분리 실측.
- Chrome 내장 번역의 준비된 언어팩을 사용한 실제 오프라인 실행(이번 내장 Chromium에서는 해당 API 미지원).
- Wi-Fi를 실제로 끈 상태 및 설치형 PWA의 재시작. 이번에는 앱 서버 종료와 번역 다운로드 금지로 검증했다.
- 대용량 실제 교재, 모든 사전팩·언어·세로쓰기의 품질 및 모바일 메모리 상한.
- 개발 서버에서 온라인 버전 갱신 직후 기동 파일 오류 안내가 한 번 나타났다. 재시도 후 정상 기동했고 이후 오프라인 새 탭/재실행은 성공했다. 동일 오류의 반복 재현 및 원인 확정은 못 했다.
