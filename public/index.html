    모델 관리

    PaddleOCR만 최초 실행 시 자동 준비합니다(약 60.8MB). Tesseract 경량·정밀은 한·영·일 통합 팩으로 선택 다운로드합니다. 번역 모델은 다운로드 버튼을 눌러 준비하세요. 모델은 현재 브라우저·사이트 주소에 저장됩니다.

    브라우저가 저장 데이터를 정리하면 다시 다운로드해야 합니다. 삭제는 앱 관리 모델 캐시만 대상으로 하며 설치 파일과 브라우저 자체 언어 팩은 포함하지 않습니다.

    번역 설정

    실험판 · 원문은 기기 안에서만 처리합니다.

    먼저 영역을 선택하거나 원문을 입력하세요. 번역 모델은 자동으로 다운로드하지 않습니다.

    OCR·번역 모델의 다운로드와 삭제는 설정 → 모델 관리에서 진행합니다. 모델이 없으면 해당 화면으로 안내합니다.

    PC는 드래그, 모바일은 손가락 드래그로 영역을 선택합니다. 선택하는 동안 페이지 넘기기는 잠시 멈춥니다. 숨김 상태의 선택한 색 글자는 OCR에 포함하지 않습니다.

    엔진 지원 상태와 라이선스

    Tesseract 경량·정밀과 PaddleOCR는 기기 내 OCR 엔진이며 Apache-2.0입니다. PaddleOCR만 최초 실행 시 자동 준비하며 Tesseract는 선택 다운로드합니다. M2M100은 MIT. NLLB는 CC-BY-NC-4.0이며 개인 학습 실험용으로 제공하고 추후 삭제를 검토합니다.

    Manga OCR·Qwen은 아직 앱의 실행 엔진에 포함되지 않습니다. 브라우저 변환·모바일 메모리·실제 책의 정확도를 확인한 뒤 추가 여부를 결정합니다.

    실제 기기 성능에 따라 실패하거나 오래 걸릴 수 있습니다. 현재 버전은 선택 영역만 처리합니다. 책 전체의 자동 번역은 포함하지 않습니다.

    현재 선택은 즉시 적용됩니다. 다음 앱 실행에도 사용하려면 기본값으로 저장하세요.

    Google Drive 동기화와 함께 사용할 수 있습니다. 백업을 불러오면 현재 데이터와 합쳐지며, 복원한 학습 기록도 Drive 동기화에 포함됩니다. 같은 자동 저장 파일을 여러 기기에서 함께 수정하지 마세요.

    버튼을 누르고 사용할 키를 입력하세요. Esc로 취소하고, 해제로 단축키를 끌 수 있습니다. 입력창·설정·번역 작업 중에는 실행하지 않습니다.

    메뉴·학습 시트·단축키 변경 후 저장하세요.

    백업 불러오기

    기존 주석과 단어는 지우지 않고 합칩니다. 같은 ID에 다른 내용이 있으면 별도 항목으로 보존합니다. 현재 저장된 설정과 읽기 위치는 백업으로 덮어쓰지 않습니다.

    복원 후 앱을 다시 불러옵니다. 기존 모델과 사전 설치 상태는 유지합니다.
